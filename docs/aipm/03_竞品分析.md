# 竞品分析文档

## 竞品范围

- 闲鱼：成熟二手交易平台，商品供给大、交易链路完整，但校内身份和线下校园场景弱。
- 校园墙/表白墙：触达快、本地化强，但内容非结构化，搜索、筛选、状态追踪弱。
- 校内论坛/贴吧：讨论和信息沉淀较强，但交易与招领流程分散，审核效率有限。
- 失物招领小程序：场景聚焦，但通常缺少二手交易、个人中心和订单记录。
- 学校官方信息平台：可信度高，但通常不承担学生间物品流转和轻交易。

## 机会点

- 不与闲鱼竞争商品规模，而是强调校内可信、低距离、线下自取和校园身份。
- 不依赖校园墙的信息流扩散，而是把物品、订单、认领、评论和状态结构化保存。
- 不把失物招领做成单点工具，而是与个人中心、认证、评论和后台审核联动。
- 用演示数据和统一 UI 提升毕业设计展示质量，让功能链路一眼可理解。

## 差异化设计

### 校园可信

通过学生证 OCR 认证、管理员审核和用户状态标签，把“是否为校内学生”从口头承诺变成可见状态。认证只作为平台信任辅助，不做真实强身份核验。

### 业务闭环

二手物品从发布、浏览、下单、支付状态、库存变化到消费记录形成闭环；失物从发布、认领申请、审核回复到个人中心记录形成闭环。

### 用户工作台

个人中心按照普通学生最关心的事项组织：我的发布、我的申请、我的订单、我的收藏和资料认证。

## 产品叙事

本项目不是“校园版闲鱼”的简单复制，而是一个面向校内物品流转的轻量工作台。它把学生身份、失物认领、二手交易、校园动态和后台审核放在同一套数据结构中，适合校园内小范围、低成本、可追踪的物品流转场景。
